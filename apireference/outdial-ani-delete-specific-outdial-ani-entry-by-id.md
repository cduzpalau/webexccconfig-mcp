# Delete specific Outdial ANI Entry by ID

**Operation Id:** deleteConfig\_9

**Description:**

Delete an existing Outdial ANI Entry by ID in a given organization.

DELETE/organization/ **{orgid}/outdial-ani/{outDialAniId}/entry/{id}**

## Request Parameters

#### Path

orgidrequiredstring

Organization ID to be used for this operation. The specified security token must have permission to interact with the organization.

example = "2f9eecc5-0472-4549-9a83-2afdae0d4ba1"

outDialAniIdrequiredstring

Resource ID of the Outdial ANI

example = "af9eecc5-0472-4549-9a83-2afdae0d4ba0"

idrequiredstring

ID of this contact center resource.

example = "af9eecc5-0472-4549-9a83-2afdae0d4ba0"
