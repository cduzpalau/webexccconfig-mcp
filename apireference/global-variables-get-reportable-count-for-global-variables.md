# Get reportable count for Global Variable(s)

**Operation Id:** getReportableCountConfig

**Description:**

Get count for all the reportable Global Variable(s) in a given organization.

GET/organization/ **{orgid}**/cad-variable/reportable-count

## Request Parameters

#### Path

orgidrequiredstring

Organization ID to be used for this operation. The specified security token must have permission to interact with the organization.

example = "2f9eecc5-0472-4549-9a83-2afdae0d4ba1"
