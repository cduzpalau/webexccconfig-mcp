# Purge inactive Desktop Layout(s)

**Operation Id:** purgeInactiveConfig\_7

**Description:**

Purge inactive Desktop Layout(s) older than the configured interval for a given organization.

POST/organization/ **{orgid}**/desktop-layout/purge-inactive-entities

## Request Parameters

#### Path

orgidrequiredstring

Organization ID to be used for this operation. The specified security token must have permission to interact with the organization.

example = "2f9eecc5-0472-4549-9a83-2afdae0d4ba1"

#### Query

nextStartIdstring

This is the entity ID from which items for the next purge batch with be selected.

example = "af9eecc5-0472-4549-9a83-2afdae0d4ba0", default = ""
