# Get specific Business Hours resource by ID

**Operation Id:** getConfig\_23

**Description:**

Retrieve an existing Business Hours resource by ID in a given organization.

GET/organization/ **{orgid}/business-hours/{id}**

## Request Parameters

#### Path

orgidrequiredstring

Organization ID to be used for this operation. The specified security token must have permission to interact with the organization.

example = "2f9eecc5-0472-4549-9a83-2afdae0d4ba1"

idrequiredstring

Resource ID of the Business Hours resource.

example = "2f9eecc5-0472-4549"
